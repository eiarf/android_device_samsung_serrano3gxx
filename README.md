# Device Configuration for Samsung Galaxy S4 Mini 3G (`serrano3gxx`)

This repository contains the device configuration for Samsung Galaxy S4 Mini 3G (GT-I9190), ported to **LineageOS 21.0 (Android 14)**.

## Specifications

| Feature | Specification |
| :--- | :--- |
| Model | Samsung Galaxy S4 Mini 3G (GT-I9190) |
| Chipset | Qualcomm Snapdragon 400 MSM8930AB |
| Modem | 3G / HSPA+ (Samsung Proprietary IPC RIL) |
| Display | 540 x 960 Super AMOLED |
| Memory | 1.5 GB RAM |
| Kernel | Linux 3.4.113 |
